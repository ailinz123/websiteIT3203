Key HTTP Concepts

These seven terms help explain how HTTP works and why its newer versions matter.

1. HTTP Request
A message a client sends to a server to ask for a resource or action. For example, a browser may request /index.html.
2. HTTP Response
The message a server returns after receiving a request. It can include a status code, headers, and content.
3. HTTP Method
A word describing the action requested by the client. Common examples include GET, POST, PUT, and DELETE.
4. Status Code
A three-digit number indicating the result of an HTTP request. For example, 200 means success and 404 means not found.
5. HTTP Header
Additional information included in a request or response. For example, Content-Type identifies the type of content.
6. Multiplexing
A technique used by HTTP/2 and HTTP/3 to let multiple streams share a connection efficiently.
7. QUIC
A secure transport protocol built over UDP. HTTP/3 uses QUIC to support independent streams and efficient connection management.
